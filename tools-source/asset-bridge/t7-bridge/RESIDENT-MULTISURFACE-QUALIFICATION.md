# Resident multi-surface v2: exact build D qualification

This source gate qualifies the closed native build D for a later separately
prepared export. It does not run the candidate, grant admission, create an
operational plan, prove a serialized model, or establish game compatibility.
The original v1 and surface-count diagnostic contracts remain separate.

## Selection and guarded evidence

`Operation` stays `ResidentExportV1`. The explicit
`ResidentMultiSurfaceV2` object contains only
`Schema: iw7.t7-resident-multi-surface/2`; extra fields, including a caller's
qualification claim, refuse. The argument is `-t7-iw7-model-v2`. A build reuse
marker without this export marker, or the reverse, refuses. Diagnostic and v2
markers cannot be mixed.

## Export limits and source tests

The existing v2 output contract allows 1–255 surfaces in ordered records, with
unchanged material order and duplicates. Model and mesh limits remain 1 MiB and
16 MiB; only the v2 manifest limit is 256 KiB. Checked work accounting uses the
correct 96-byte T7 surface: `256 + 384*N + 60*V + 12*T`, bounded by 16 MiB.
Admission remains 6/8 GiB; native/group/cleanup deadlines remain 120/200/5 seconds.

`Test-T7ResidentExport.ps1` includes the original export, diagnostic, v2 output
and build-qualification suites. `Test-T7CataloguePublication.ps1` covers the
unchanged publication path. Synthetic cases reject missing or mixed markers,
crossed pins, failed stages even with an EXE tuple, altered headers/transitions,
unclosed hosts, inferred exits, wrong witness identities and changed F inputs.

`Test-T7ResidentMultiSurfaceBuild.ps1` optionally accepts
`-ReviewedBuildPlanPath` and `-IndependentWitnessPath`. That mode retains and
hashes only explicitly listed small source/response/JSON texts under an 8 MiB
budget, then calls the same qualifier using a partial read-only context.
It has no operational export paths, arguments, admission or native invocation.

Validation on 2026-10-13: 309 resident export, 230 diagnostic/F-transition,
277 v2 geometry, 244 build-qualification and 307 publication checks passed
(1367 total). The reviewed-text mode passed on D with 1,075,712 bytes of

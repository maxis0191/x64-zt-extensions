## Bounded interpretation after a separately authorized Run

Review the complete retained instruction rows, not only the literal +0x58 list.
Track entry R9 through explicit register copies, stack saves/reloads and address
arithmetic separately on each control-flow path. Distinguish the address P from
the value loaded at P, stores through P, stores through a derived address and
overlapping wider stores. Record width, source-value category, path predicates
and every preceding unexamined call before naming a candidate writer.

Treat partial/32-bit writes, unresolved loads, conflicting joins and volatile
registers across calls as lost or conditional provenance. A same-named register
after a call is insufficient. Nonvolatile preservation is an ABI assumption,
not proof of callee behavior. Queue/decode order is not runtime write order;
loops and conditional paths do not prove which write executes first. The
existing reader remains a bounded control-flow reporter, not an alias solver.

Stop any first-writer conclusion at an unexamined call, indirect target, alias
loss, ambiguous ownership, incomplete decode, unproved branch feasibility or
limit. Preserve exact frontiers and partial evidence. Missing/overlapping
ownership and non-instruction boundaries are refused; indirect branches are
reported unresolved. Calls are recorded without following them. Do not guess
bytes, inspect a second seed or enlarge a ceiling to make a refusal disappear.

If H only forwards P, or its dataflow is not informative, return that exact
handoff or ambiguity without another walk. The minimal source-first alternative

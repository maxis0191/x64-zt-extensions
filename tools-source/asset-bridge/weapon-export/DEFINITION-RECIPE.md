# Neutral definition CPP recipe: Source only

This recipe prepares the ten-stage8/28/36/100 cohort after a distinct admitted
H1 Analysis/PREP GO. It never runs a compiler, inspects PE/PDB/SDK/retail bytes,
acquires a lease, creates an owner or adopts a historical process. Its default
validates bounded Source/JSON and reports `ExpectedNoEffects=true`; only the
explicit `--prepare` path writes a fresh owned Source output.

`prepare_definition_cohort.py` reads the exact immutable closed CPP J plan and
qualification **as historical metadata**. It preserves the1151 expected retained
input declarations,171 parent declarations,412 retained objects and413-object
link structure. It substitutes one future fresh IW7 TU. It does not reopen the
J executable/symbols, inherit its62-check qualification, or copy any actual
owner/context/creation tuple into the new operation. J/533c is not a candidate
for this new mode. New `CandidateBytes` and `CandidateSHA256` remain null.

The builder must execute from a reviewed composed Source package. It verifies
the package manifest/revision and all owned implementation hashes, then uses
the existing `prepare_module.stage` exact native Source generator. The compiled
fixture sources are the actual files exported by that package, including the
100-case production-gate fixture and the four typed access/readset/field/gate
headers. A small forced-include header defines `IW7_NATIVE_STRUCTS_HEADER` to
the exact already-declared native header. `/FI` avoids fragile quoted `/D`
macro values; no native header or bool/enum layout is synthesized.
MSVC's documented [`/D` parsing](https://learn.microsoft.com/en-us/cpp/build/reference/d-preprocessor-definitions?view=msvc-170)
strips command-line quotation marks; the forced-include file supplies an ordinary
C++ string literal instead. Its actual compilation remains unmeasured.

The fixed definition response compiles `test_definition_readset.cpp`, emits its
own object/EXE/PDB/dependency report, and keeps `/MT /DNDEBUG /W4 /WX /Y-` with
the existing sealed environment. The other five response files retain their
historical Source content with only owned output-root changes. The original
H1 CPP NoExit capsule is rewritten only for fresh paths and the new plan hash;
its owner/job/closure behavior is not replaced. RunRoot remains absent after
Source preparation. The ten stages are:

1. name compile/test8;
2. argv compile/test28;
3. primary compile/test36;
4. definition compile/test100;
5. IW7 TU;
6. link.

These are172 **authored** checks, not172 executed checks. A new C++ candidate,
then a separately admitted extraction, still require their own Root decisions.

## Ordinary CPP DEFAULT checks actual fixture wiring

The new plan supplies `DefinitionFixture`. Before ordinary DEFAULT can return,
the player build runner checks the normalized Source hashes of the real100-case
fixture and all four headers. It verifies unique prepared bindings, all six
owned include-coverage entries, the exact forced-include definition, and the
entire fixed definition response. A comment containing a100-check marker is
not accepted as a substitute fixture, even if its metadata hash is updated.
An injected response/source or alternate native header is refused.

The native structs path/354227-byte/raw SHA declaration must match the original
retained input. DEFAULT does not stat/open/hash that retained header, compiler,
SDK, PE, symbols or retail. Their actual verification remains behind admission.
The shared bounded Source reader rejects opaque extensions before even querying
their filesystem path, including a forged PE entry in SourceBindings.
Successful DEFAULT reports `DefinitionFixtureSourceVerified=true`, null
candidate fields and false native-types/input-hash/run-root/lease/ready flags.
This checks Source wiring; it does not establish compilation, ABI or runtime
header compatibility.

Tests use small owned Source outputs and the real exported fixture/header bytes.
They execute the actual PowerShell DEFAULT, prove updated metadata cannot make a
stub fixture pass, reject an injected response, and show the missing fake native
header/compiler remain unopened. Builder tests substitute only the external
native stage on tiny owned Source fixtures; production exposes no bypass for
its pinned native generator. No actual Analysis/PREP result is implied.

## Future Analysis capsule parameters

The separately reviewed capsule calls the builder with `-B -S`, then the
ordinary player build DEFAULT **without** `-Run`, inside the existing original
H1 Analysis owner and lease. It uses fresh roots/key/physical host witness.
Historical A/F/J capsules are immutable Source patterns, never adopted contexts.
Setup, factory and Start remain inside group/phase clocks, and any uncertain
closure retains the same original owners, guards and lease. The preparation
capsule itself must be independently reviewed before its Analysis GO.

Inputs are `--source`, `--source-revision`, `--source-manifest-sha256`, `--base`,
`--native-source-root`, `--output`, plus `--prepare` only in admitted PREP.
The output contains Source/JSON/RSP and a future CPP capsule; it contains no
binary candidate or current qualification. `recipe-source-receipt.json` keeps
CPP/extraction/mechanics readiness false. The ordinary DEFAULT's actual receipt
is produced only during that future admitted Analysis operation.

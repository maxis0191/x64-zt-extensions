## Graphics and future execution plan

Material C requires explicit `-GraphicsProfile Full`. The existing calculator
reserves **16 GiB physical and 16 GiB commit** for one client plus the dedicated
with debugger disabled. With debugger enabled the existing overhead still applies.
The historical default remains Reduced at 12/12 GiB. The same selected profile
reaches both reservation and client launch, and native captures check fresh
picmip/bump/spec telemetry. Full uses zero for all three, retaining 1280×720/30 fps;
this is not normal-resolution performance acceptance. Never lower the reservation
to make admission pass.

A reviewable invocation adds the following to the existing exact vertical
GameRoot/CandidateRoot/package/provider/SDK bindings. This example is deliberately
DryRun and grants no launch permission:

```powershell
./ops/Agent-Lab.ps1 @reviewedCommonInputs `
    -ObservationMode vertical -Debugger:$false `
    -VerticalAssetVariant MaterialC -GraphicsProfile Full `
    -VerticalFFPath $reviewedMaterialCFF `
    -VerticalFFSHA256 B37C7564722AF8E88AFE8503E2A6F5D2BDD69B6EE13C921843C051E7070F7A72 `
    -VerticalFFBytes 1956 `
    -TicketInitObserver `
    -TicketInitObserverSHA256 4E5E662FEF7E84272775790FB1FB7E3DADC2443B10DAEA90180E2BFE33DE8D54 `
    -DryRun
```

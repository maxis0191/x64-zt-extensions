# Creation tools: one table

This table covers this repository only. Every tool of every repository is listed in `docs/TOOLS-INDEX.md` of the
server repository (iw7-paris-server). Other documents of this repository: `docs/INDEX.md`.

Every tool area for making game content that lives in this repository, on the main line. Paths are relative to the
repository root. Test commands run from the repository root with Python 3.12 (stdlib only, unless a row says
Blender or a local game dump is needed). "Proven in the running game" is copied from the area's own document
(STATUS, NOTES, README or the commit that recorded the witness); `not recorded` means the area's documents say nothing,
`no` means they say it was not run in the game.

Game files, dumps, audio and built fastfiles are never committed. Every tool reads them from a local path you give it.

| Collision boxes | Clip boxes from a voxelised surface (openings stay open) for the map generator. | `tools-source/asset-bridge/env-model/collision_boxes.py` (library, called by the port command) | `tools-source/asset-bridge/env-model/README.md` | same as above | not recorded |

| Hero kit (outfits and materials) | Packs authored maps into the hero material layout, builds a material clone zone, adds an outfit row, ships a hero set in one command. | `python -I tools-source/iw7-skinned-writer/ship_heroes.py --config <config> --out <dir>` (start from `ship_heroes.example.json`); materials: `hero_material.py`, `hero_material_zone.py` | `tools-source/iw7-skinned-writer/NOTES.md` (sections "New material route" and "Hero outfits ship") | the ship config reader is tested in the check above; packing and material zones need Blender and a game dump and are not in the suite | partly (2026-11-09: the material route and outfit drawn in the game; the first full hero set was rated not shippable by reviewers, the second build was not run) |
| Zombie kit | Fits an authored mesh to the stock zombie parts (six body parts, five damaged gibs, caps), writes the models, materials and the cloned scriptable. | `python -I tools-source/iwz-zombie-kit/run_zombie.py --config tools-source/iwz-zombie-kit/configs/zombie_M1.json` (local inputs through `IWZ_*` environment variables, see the README) | `tools-source/iwz-zombie-kit/README.md`, `NOTES.md` | `python -B -m unittest discover -s tools-source/iwz-zombie-kit` (10 tests on synthetic data: runner inputs, part tables, scriptable clone); check `tools-source-iwz-zombie-kit`. ## Sounds

| Area | What it does | Entry command | Document | Test command | Proven in the running game |
| --- | --- | --- | --- | --- | --- |
| Sound bank tools | Reads the game's sound banks (`.sabl`, `.sabs`) and extracts FLAC; writes a bank source for a map or mod from stock rows plus your own FLAC (variants, loops, sound zones, re-trigger twins). | `python tools-source/asset-bridge/iw7-audio/iw7_sab.py list <bank>`; `python tools-source/asset-bridge/iw7-audio/iwz_audio_bank.py --spec <spec>.json --out <asset root>` | `tools-source/asset-bridge/iw7-audio/README.md` | `python -B -m unittest discover -s tools-source/asset-bridge/iw7-audio` (14 tests); registered as the check `tools-source-asset-bridge-iw7-audio` | yes (2026-11-07 and 2026-11-08 usermap runs; one-shots and beds played, music with non-1024 FLAC blocks stayed silent and is now re-encoded) |
| Per-weapon loudness | Recipe key `sound_gain_db` raises every alias volume of a ported weapon (capped like stock); chain layers take their own stock channel, random variants are kept. | `python tools-source/asset-bridge/t7-weapons/t7_port_weapon.py --config port-config.json --weapon <name> --out <dir>` (reads `recipes/<name>.json`) | `tools-source/asset-bridge/t7-weapons/STATUS.md`, `tools-source/asset-bridge/t7-weapons/recipes/` | `python -B -m unittest discover -s tools-source/asset-bridge/t7-weapons -p "test_t7_weapon_sound.py"` | yes for the measurement and the channel fix (2026-11-09, audio6 witness: levels measured, shots start 100 to 200 ms after the press); the recorded gains (+6 dB, +4 dB for Thundergun) were chosen from it, a recheck after applying them is not recorded |

| --- | --- | --- | --- | --- | --- |
